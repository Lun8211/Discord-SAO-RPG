## 🌟 核心特色

### 1. 完整 SAO 艾恩葛朗特世界觀
- **雙模式登入**：標準模式（Standard：倒地可由隊友以轉移水晶救援）與 **死亡遊戲一命模式（Hardcore）**，生死紀錄即時銘刻於第 1 層黑鐵宮 **生命之碑（Monument of Life）**。
- **無玩家魔法**：純物理劍技戰鬥系統與 **四軸傷害／抗性（斬／刺／打／龍）**，75% 抗性上限並隨樓層遞增抗性穿透（F100 達 65%）。
- **圈內安全區 vs 野外／迷宮區**：鍛造、洗點、市集與公會倉庫皆須於圈內安全區操作；光標顏色（🟢 綠標／🟠 橙標／🔴 紅標）隨主線抉擇業力動態變化。
- **情報屋與系統日誌**：**阿爾狗的情報屋**即時追蹤全服攻略前線與首殺名人堂（未觀測頭目階段自動遮蔽為 `???`）；**結衣終端機（MHCP-001）**於關鍵樓層逐步解鎖卡迪納爾核心檔案。

所有 100 層生態、怪物、寶箱、武器、劍技、道具、配方與頭目腳本皆由 `src/rpg/content/*.json` 驅動，啟動時自動通過嚴格 Schema 與參照完整性驗證（零懸空引用）：
- **10 大主題生態樓層模板**（F1–F100 單調數值成長）＋ 25 層經典劇情覆寫（第 1 層起始之鎮、第 27 層水晶無效化陷阱、第 50 層阿爾格特、第 55 層水晶石英礦脈、第 74/75 層、第 100 層紅玉宮）。

  - `F1` 狗頭人領主・伊爾方（P2 棄盾拔野太刀）
  - `F10` 武士領主・加賀智（千蛇劍陣回復需雙人 Switch 破陣）
  - `F20` 瘴氣樹王・瓦爾多拉斯、`F25` 雙面獄魔・阿比斯瓦德（喊話機制）
  - `F30` 冰霜凱撒、`F40` 荒野獄長
  - `F50` 鋼鐵審判官・阿爾格特（尾刀掉落名品**闡釋者 Elucidator**，解鎖獨有劍技試煉）

### 3. 真人多人組隊、大型攻略團與即時同步共鬥
- 支援 **2～6 人一般隊伍** 與 **最多 24 人大型攻略團（Raid Alliance）**，所有真人玩家可直接在 Discord 公開大廳點擊加入、選擇職責（`前排坦 / 輸出 / 破防 / 輔助`）、切換準備與開啟 **藥水共享（我要出藥）**。
- **同步回合防卡死設計**：全員提交指令後立即結算；25 秒逾時自動防禦，連續 2 回合未操作自動進入【沉睡／託管】，絕不卡死攻略進度。
- **SAO 招牌戰術**：`⇄ 交換（Switch）` 轉移仇恨、累積連攜增傷（+25%～+75%）與破防槽；精準彈反（Parry）、太刀納刀居合、背刺加成、隊伍集體傳送與轉移水晶救援瀕死隊友。
- **尾刀獎勵（LA Bonus）、全員保底掉裝與待領信箱**：精準歸屬最後一擊玩家並頒發名品掉落，同時每位共鬥隊友皆獲樓層階級裝備與強化結晶；背包滿時自動安全轉存至待領取信箱並優先依稀有度領取。

## 🚀 快速啟動與開發驗證

```bash
# 1. 建立虛擬環境並安裝依賴（Python 3.11+）
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scripts\activate
pip install -r requirements.txt

# 2. 設定環境變數（切勿提交真實 .env）
cp .env.example .env
# 編輯 .env 填入 DISCORD_BOT_TOKEN

# 3. 啟動機器人
python bot.py
```

Windows 使用者可直接雙擊 `start_bot.bat` 啟動、`stop_bot.bat` 安全存檔停止、`update_bot.bat` 一鍵從 GitHub 更新至最新版（自動備份存檔並保留 `.env` 與 `data/rpg.db`，支援 Git 與免 Git 下載兩種環境），或執行 `setup_autostart.bat` 設定開機無黑窗自動常駐。

### 測試與建置驗證
```bash
python -m compileall -q bot.py src tests
python -c "from src.rpg.content.loader import load_and_validate_all; load_and_validate_all()"
pytest -v
```
